# Tiered routing: when a cascade stops paying for itself

Generated by `python scripts/generate_results.py`. Do not edit by hand.

> **Cost arithmetic only.** This repo does *not* establish that
> escalation improves answer quality — that needs a labelled quality
> set and a real model, neither of which exists here. What follows is
> what a cascade costs at a given escalation rate, which is the part
> the breakeven question needs.

## Inputs

- Cheap tier: $0.15/M in, $0.6/M out
- Strong tier: $2.5/M in, $10.0/M out
- Request mix: 500 prompt + 200 completion
- Reproduce: `python scripts/generate_results.py`

## Blended cost by escalation rate

An escalated request pays for **both** calls. That double charge is
what makes a cascade stop paying off well before every request
escalates.

| escalation rate | blended $/request | vs strong-only |
|---|---|---|
| 0% | $0.000195 | -94% |
| 10% | $0.000520 | -84% |
| 25% | $0.001007 | -69% |
| 50% | $0.001820 | -44% |
| 75% | $0.002632 | -19% |
| 90% | $0.003120 | -4% |
| 100% | $0.003445 | +6% |

**The cascade breaks even at an escalation rate of 94%.** Above
that, the cheap tier is a pure tax: you pay for a filter that rarely
filters, and simply calling the strong model directly is cheaper.
Asserted: at 100% escalation the cascade costs more than strong-only.

This is the number to compare a measured escalation rate against. It
converts "is our cascade worth keeping" from an opinion into a
threshold — and note how *high* it is here: with a 17x price gap
between tiers, a cascade survives a lot of escalation before it loses.

## Limitations

- The confidence signal used by the gateway's default router is a
  **stand-in** (`heuristic_confidence`): it detects hedging and
  truncation, is trivially gamed, and cannot detect a confidently
  stated wrong answer. No escalation *rate* is claimed here as a
  result — only the cost of whatever rate a real signal produces.
- Assumes both tiers see the same token counts, which overstates the
  strong tier's cost slightly when it is given a shorter prompt.
